# Security Policy

## Supported versions

Security fixes are maintained for these versions only:

| Version | Supported |
| --- | --- |
| Current `main` branch | Yes |
| Latest development release published on PyPI | Yes |
| Earlier development releases | No |

DataJig is experimental and has not reached a stable `1.0` compatibility
promise. Users should upgrade to the latest development release when a security
fix is published.

## Reporting a vulnerability

Please do not open a public issue that includes exploit details, proof-of-concept
code, sensitive data, or an unpatched vulnerability.

When GitHub private vulnerability reporting is available, use the repository's
**Security** tab and select **Report a vulnerability**. Include:

- the affected version or commit;
- the affected command, artifact, or workflow;
- reproduction steps and the security impact;
- any known mitigations; and
- a safe way to contact you for follow-up.

If private GitHub reporting is unavailable, contact the maintainer directly at
liukj7@gmail.com. Do not disclose the vulnerability publicly until a fix or
coordinated disclosure plan is ready.
